# Sistema Control

**Plataforma web para la gestión de servicios de Soporte Técnico del INEA**

Sistema Control es una aplicación web desarrollada para administrar y dar seguimiento a los servicios de **software, hardware y redes** proporcionados por el Departamento de Servicio Técnico del INEA.

El sistema fue desarrollado en entorno Windows y está diseñado como una solución 100% web, permitiendo acceso completo desde computadoras, tablets o teléfonos móviles mediante un navegador.

---

## Descripción

Sistema Control centraliza la gestión de incidencias técnicas, optimizando el registro, seguimiento y control de los servicios tecnológicos. Su enfoque web permite disponibilidad continua y acceso remoto sin necesidad de instalar software adicional en los dispositivos cliente.

---

## Características Principales

* Gestión de servicios de **software, hardware y networking**
* Registro y seguimiento de solicitudes técnicas
* Acceso desde cualquier dispositivo con navegador web
* Interfaz responsiva adaptable a móviles y computadoras
* Base de datos centralizada

---

## Tecnologías Utilizadas

* **PHP**
* **MariaDB**
* **Bootstrap**
* **JavaScript**
* **HTML5 / CSS3**

---

## Requisitos del Sistema

### Servidor

* Servidor web en windows
* PHP 8.x o superior
* MariaDB 10.x o superior

### Cliente

* Navegador web moderno (Chrome, Edge, Firefox, Safari)

---

## Objetivo

Proporcionar una herramienta eficiente, centralizada y accesible para la administración de servicios técnicos, mejorando la organización, trazabilidad y manejo de datos del Departamento de Servicio Técnico del INEA.
